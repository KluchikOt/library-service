Что реализовано

Книги

CRUD: создание, просмотр, обновление, удаление
Поиск по названию, автору, ISBN
Фильтрация по году издания и доступности
Пагинация и сортировка списков

Читатели

CRUD
Валидация email и номера телефона
Дата регистрации проставляется сервером

Выдачи

Выдача книги читателю с указанием срока возврата
Возврат книги с автоматическим обновлением статуса и количества доступных экземпляров
История выдач читателя
Список просроченных выдач (должники)

Общее

Трёхслойная архитектура Controller → Service → Repository, DTO для обмена данными
Кастомные исключения и глобальный обработчик ошибок с понятными сообщениями
Пара юнит тестов
Запуск через Docker Compose и Makefile


Поиск и фильтрация

GET /api/books/search — параметры необязательные, объединяются через «И»:

Параметр	Условие
title	точное совпадение названия
author	точное совпадение автора
isbn	точное совпадение ISBN
publicationYear	год издания
availability	true — есть свободные экземпляры, false — все на руках
